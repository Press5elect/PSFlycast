# Every setting's words

Generated by `shell/ps5/tools/settings-table.py review` from the table in that script: 208 settings in 8 areas. Source **F**: Flycast's label and description word for word (48); **f**: Flycast's own words joined or shortened (17); **P**: PSFlyCast's, written as Flycast writes them (143). Level: E Essentials, M More, X Everything. Flags: g a game can have its own value, G only a game has it, r takes effect at the next start of PSFlyCast, n at the next game. *Was* is the label before.
